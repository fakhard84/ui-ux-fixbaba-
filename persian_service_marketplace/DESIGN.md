## Brand & Style

This design system defines an on-demand home appliance repair marketplace crafted natively for Persian-speaking users. The brand balances technical rigor and industrial dependability with urgent, warm responsiveness. 

### Brand Personality & Tone
- **Dependable & Competent:** Deep navy foundations evoke mechanical expertise, structural integrity, and institutional trust.
- **Urgent & Energizing:** Saturated coral orange highlights convey swift action, direct support, and friendly resolution for stressful household emergencies.
- **Culturally Grounded:** Tailored for seamless Right-to-Left (RTL) reading flows, Persian numeric formatting, and regional localized idioms.

### Design Style: Modern Apple-Inspired Tactile Marketplace
The visual language fuses crisp Apple-style rounded geometry (`14px`–`28px` corner radiuses) with tactile depth:
- Multi-tier elevated surfaces tinted with deep navy undertones rather than neutral greys.
- Glassmorphic navigation planes using high-saturation backdrop blurs (`blur(20px)` to `blur(40px)`).
- Kinetic feedback powered by warm coral glows (`shadow-glow`), subtle vertical hover translations (`translateY(-4px)`), and decisive interactive state styling.

## Colors

The color palette establishes visual authority through deep mechanical blues and accents crucial actions with vivid safety-coral tones.

### Brand Roles
- **Primary (`#102a43`)**: Anchor for typographic hierarchy, prominent headers, dark surfaces, and rich foundational gradients.
- **Secondary (`#f97316`)**: Reserved for high-priority interactive conversion points: primary call-to-action buttons, emergency booking triggers, active navigation markers, and focus boundaries.
- **Tertiary (`#059669`)**: Conveys operational success, verified technician badges, positive wallet balances, and completed status states.
- **Neutral (`#829ab1`)**: Mid-tone slate navy balancing borders, subtle secondary metadata, and inactive interactive elements without dropping into sterile monochrome greys.

### Dark Mode Principles
Dark mode switches from cold neutral black to deep oceanic slates (`#020617` background, `#0f172a` container cards). Borders transition to navy-700 (`#334e68`), and text shifts upward to navy-200 (`#bcccdc`) for high-contrast, eye-strain-free reading.

### Semantic Status Colors
- **Open / Requested**: Info blue (`#2563eb`) on soft blue container.
- **Quoted**: Purple (`#9333ea`) indicating pending estimates.
- **Accepted / Verified**: Emerald green (`#059669`).
- **In Progress**: Amber (`#d97706`) denoting active technician dispatch or diagnostic work.
- **Urgent**: High-saturation red (`#dc2626`) paired with distinct alert iconography.

## Typography

Typography is governed by a strict dual-font setup tailored for the Persian script with RTL reading discipline:

### Font Roles
- **Lalezar (Display & Numeric Authority)**: Used exclusively for prominent titles (Display, H1, H2) and high-impact numerical readouts (wallet balances, service pricing, metrics). Numbers render with high visual personality and tabular stability.
- **Vazirmatn (Interface & Text Engine)**: Handles structural UI copy, paragraph text, form inputs, button labels, and system microcopy across weights 400 (Regular), 500 (Medium), and 600/700 (SemiBold/Bold).

### Bi-Directional Layout Rules
- Global application context operates under `dir="rtl"` with `lang="fa"`.
- Exceptions: System-generated IDs, tracking hashes, phone numbers, and IBAN/SHEBA banking strings must enforce `dir="ltr"` and `font-variant-numeric: tabular-nums` to ensure correct linear recognition.

## Layout & Spacing

The layout is built on a standard **4px harmonic baseline grid** scaling to an Apple-style fluid container model.

### Grid & Breakpoints
- **Mobile (< 768px)**: Single-column fluid view with `1rem` outer canvas padding (`margin`) and `1rem` column gutters (`gutter`). Bottom content must enforce a minimum padding buffer of `calc(4.5rem + env(safe-area-inset-bottom))` to clear the floating mobile navigation shell.
- **Tablet (768px – 1023px)**: 6 to 8 fluid columns with `1.5rem` margins and `1rem` gutters.
- **Desktop (≥ 1024px)**: 12-column layout constrained to max container widths:
  - Standard App / Marketplace: `max-w-7xl` (`1280px`) with auto centering.
  - Chat & Workspace Interfaces: `max-w-5xl` (`1024px`).
  - Booking Funnels & Account Management: `max-w-4xl` (`896px`).
  - Margins scale to `2rem` (`margin-lg`) with `1.5rem` (`gutter-lg`) gutters between cards.

### Layout Rhythm
- Internal card padding defaults strictly to `1.5rem` (`space-lg`) on desktop and reduces to `1rem` (`space-md`) on mobile screens.
- Standard inline icon-to-label gaps maintain an exact `0.5rem` (`space-sm`) cadence.

## Elevation & Depth

Visual hierarchy leverages brand-tinted ambient shadows and saturated glass frosted layers to communicate elevation.

### Tinted Ambient Shadows (Light Mode)
Surfaces avoid neutral charcoal drop-shadows, applying instead deep navy pigmentation (`rgba(16, 42, 67, ...)`):
- **Base Cards (`shadow-sm`)**: `0 1px 3px rgba(16, 42, 67, 0.08), 0 1px 2px rgba(16, 42, 67, 0.04)`
- **Interactive / Elevated Cards (`shadow-md`)**: `0 4px 6px -1px rgba(16, 42, 67, 0.08), 0 2px 4px -2px rgba(16, 42, 67, 0.05)`
- **Marketplace Listings (`shadow-lg`)**: `0 10px 15px -3px rgba(16, 42, 67, 0.08), 0 4px 6px -4px rgba(16, 42, 67, 0.04)`
- **Modals & Filter Sheets (`shadow-xl`)**: `0 20px 25px -5px rgba(16, 42, 67, 0.10), 0 8px 10px -6px rgba(16, 42, 67, 0.04)`

### Interactive Glows
- **Primary CTA Hover Glow (`shadow-glow`)**: `0 0 30px rgba(249, 115, 22, 0.20)`, paired with a `-4px` Y-axis lift on `cubic-bezier(0.16, 1, 0.3, 1)`.

### Dark Mode Elevation
Elevated layers swap from navy-tinted shadows to deep ambient black occlusions (`rgba(0, 0, 0, 0.25)` to `rgba(0, 0, 0, 0.40)`), creating depth through contrast boundaries and subtle 1px border lines (`#334e68`).

### Glassmorphism
- **Header Glass (`glass-strong`)**: `background: rgba(255, 255, 255, 0.90)` (Dark: `rgba(15, 23, 42, 0.90)`) paired with `backdrop-filter: blur(40px) saturate(200%)`.
- **Floating Overlays & Chips (`glass`)**: `background: rgba(255, 255, 255, 0.80)` with `backdrop-filter: blur(20px) saturate(180%)`.

## Shapes

The interface embraces a distinctive Apple-inspired rounded curve architecture that softens technical data while preserving clear geometry.

### Radius Assignments
- **Controls & Small Elements (`14px` / `rounded-apple`)**: Interactive buttons, input text boxes, select menus, dropdown items, and task cards.
- **Panels & Dialogs (`20px` / `rounded-apple-lg`)**: Modal windows, intermediate panels, floating chat modules, and flyout navigation cards.
- **Section Cards & Hero Blocks (`28px` / `rounded-apple-xl`)**: Primary service category cards, wallet account containers, and major marketplace request listings.
- **Full Rounded (`9999px` / `rounded-full`)**: Floating Action Buttons (FAB, 56px), status pill badges, technician verification chips, and active indicator rings.

### Outlines & Focus Borders
- Standard structural card borders: `1px solid #d9e2ec` in light mode, `1px solid #334e68` in dark mode.
- Interactive focus states use an assertive offset outline: `2px solid #f97316` with a `2px` offset.

## Components

### Buttons & CTAs
- **Primary Action**: Gradient fill `linear-gradient(135deg, #f97316 0%, #ea580c 50%, #c2410c 100%)`, text `#ffffff`, border radius `14px`, height `48px` (desktop) / `52px` (mobile). Hover triggers `shadow-glow` and `translateY(-2px)`.
- **Secondary Action**: Background transparent or `#f0f4f8`, border `1px solid #d9e2ec`, text `#102a43`. Dark mode: background `#0f172a`, border `#334e68`, text `#bcccdc`.
- **Mobile FAB**: 56px circular button (`rounded-full`) fixed at bottom-center or trailing edge, coral gradient with `ph-plus` Phosphor bold icon.

### Form Inputs & Selects
- Height `48px`, border radius `14px`, background `#ffffff` (or `#f1f5f9` inside nested panels), border `1px solid #d9e2ec`.
- Text color `#102a43`, placeholder `#829ab1`. 
- Leading/Trailing icons use Phosphor line style at `20px`.
- Focus state: border color `#f97316`, shadow ring `0 0 0 3px rgba(249, 115, 22, 0.15)`.
- Dark mode inputs use `#1e293b` with border `#475569` and text `#e2e8f0`.

### Status Badges & Chips
- Structure: Height `26px` to `30px`, radius `9999px`, horizontal padding `12px`, inline icon or colored `8px` circle indicator.
- Open: Background `#dbeafe`, text `#1e40af`, dot `#2563eb`.
- Quoted: Background `#f3e8ff`, text `#6b21a8`, dot `#9333ea`.
- Accepted: Background `#dcfce7`, text `#166534`, dot `#059669`.
- In Progress: Background `#fef3c7`, text `#92400e`, dot `#d97706`.
- Urgent: Background `#fee2e2`, text `#991b1b` with fire icon (`ph-fire-fill`).

### Cards & Container Panels
- Base Card: Background `#ffffff`, border `1px solid #d9e2ec`, radius `20px` or `28px`, shadow `shadow-sm`. Hover on interactive cards applies `shadow-lg` and `translateY(-4px)` over `300ms ease-out`.
- Dark Mode Card: Background `#0f172a`, border `1px solid #334e68`.

### Checkbox & Radio Buttons
- Radio Cards: Full-card selectable items with radius `14px`. Unchecked uses border `1px solid #d9e2ec`. Checked uses border `2px solid #f97316` and background `#fff7ed` (light) / `#102a43` (dark).
- Checkbox: Custom box radius `6px`, checked fill `#f97316` with white checkmark icon.

### Specialized Marketplace Components
- **Service Request Stepper**: 48px circular nodes with `Lalezar` numerals, connected by a 2px horizontal rule. Completed steps show `#059669`, active step displays `#f97316`, upcoming steps use `#d9e2ec`.
- **Technician Verification Badge**: Pill-shaped chip featuring `ph-seal-check-fill` in emerald green (`#059669`) with text `متخصص تأییدشده`.
- **Floating Mobile Navigation Bar**: Fixed bottom bar with `glass-strong` background, housing regular line Phosphor icons which transition to `ph-fill` and coral-500 color upon selection.
